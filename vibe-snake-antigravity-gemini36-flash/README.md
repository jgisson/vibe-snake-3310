# Vibe Snake 3310 - Antigravity Gemini 3.6 Flash Edition

A retro Nokia 3310 Snake game implementation built using **Antigravity** and **Gemini 3.6 Flash**.

## Features

- **Authentic Nokia 3310 Aesthetic**: Embedded canvas aligned precisely over the Nokia 3310 high-res photo screen.
- **Interactive Photo Keypad**: Clickable hotspots over real phone buttons (Navi key, soft keys, and Numpad 1-9, *, 0, #).
- **Multiple Color Themes**: Green LCD, Amber Glow, Matrix Monochrome, and Cyber Neon themes.
- **Adjustable Speed & Wall Modes**: Toggle between Normal/Fast/Slow speeds and Solid vs. Wrap-around (Portal) wall modes.
- **Audio Effects**: Built-in sound effects generated dynamically via Web Audio API (toggleable sound).
- **Persistent High Scores**: Track and save personal best scores across sessions via `localStorage`.

## Setup & Running

Simply open `index.html` in any web browser to play.

## Controls

- **Movement**: Arrow keys (`▲` `▼` `◄` `►`) or Numpad keys (`2`, `8`, `4`, `6`).
- **Start / Pause**: Spacebar, `Enter`, or Numpad `5`.
- **Restart**: `R` key or Navi button.
- **Toggle Sound**: `M` key or `*` key.
- **Reset High Score**: `#` key.
